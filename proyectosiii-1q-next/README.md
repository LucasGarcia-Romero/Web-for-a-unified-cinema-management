
# CineFinder 🎥

**CineFinder** is a web application developed in **React** that consolidates information from all available cinemas into a single platform. Its goal is to simplify the search and selection of movies, cinemas, and schedules quickly and conveniently.

## Main Features  
- **Optimized Search:** Find the movie you want to watch in the cinema and at the schedule that best suits you.  
- **Exclusive Deals:** Discover promotions and discounts to enhance your experience.  
- **Food Options:** Check available menus to enjoy during the screening.  

## Prerequisites  
Make sure you have installed:  
- Node.js  
- npm  

## Steps to Run the Project  
1. Start the server from the corresponding folder:  
   ```bash
   node cinemaListApiDiego.js
   ```  
   Location:  
   `PROYECTOSIII\proyectosiii-1q-next\backend\apiCinema\`  

2. Start the client:  
   ```bash
   npm run dev
   ```  
   Location:  
   `.\proyectosiii-1q-next\`
